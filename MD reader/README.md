# mdview

Легкий переглядач `.md` файлів для Windows. Відкриває Markdown у браузері з темним стилем — без IDE, без установки важких застосунків.

## Вимоги

- Python 3.x — [python.org](https://www.python.org/downloads/)
- Бібліотека `markdown`:
  ```
  pip install markdown
  ```

## Встановлення

1. Скопіюй `mdview.py` і `mdview.bat` в одну папку, наприклад `C:\Tools\mdview\`
2. Перевір що працює — перетягни будь-який `.md` файл на `mdview.bat`

## Зробити дефолтним переглядачем для .md

### Варіант A — через bat файл

1. ПКМ на будь-якому `.md` файлі → **Відкрити за допомогою** → **Вибрати інший застосунок**
2. Внизу **Більше застосунків** → **Шукати інший застосунок на ПК**
3. Вибери `mdview.bat`
4. Постав галку **Завжди використовувати цей застосунок**

> Windows може не дозволити встановити `.bat` як дефолтний — тоді використовуй варіант B.

### Варіант B — конвертувати bat в exe (рекомендовано)

1. Завантаж [Bat To Exe Converter](https://bat-to-exe-converter.en.softonic.com/) (безкоштовно)
2. Відкрий `mdview.bat`, збери `mdview.exe`
3. ПКМ на `.md` → **Відкрити за допомогою** → **Вибрати інший застосунок** → вкажи `mdview.exe`
4. Постав галку **Завжди використовувати цей застосунок**

Після цього подвійний клік на будь-якому `.md` файлі відразу відкриє його у браузері.
